# claude

Kleine Bausteine für Claude Code zum Mitnehmen. Jeder Ordner hat ein README mit einer Anleitung, die Claude selbst ausführen kann („Installiere den Stop Hook von dieser URL: <URL>“ bzw. „Installiere den Skill von dieser URL: <URL>“).

| Ordner | Was |
|---|---|
| `hooks/stop-pure-ids` | Stop-Hook: nackte Doku-IDs in Antworten werden in Klartext aufgelöst |
| `skills/single-question-mode` | Skill: offene Fragen einzeln durchgehen, mit Empfehlung und Fortschrittsbalken |
